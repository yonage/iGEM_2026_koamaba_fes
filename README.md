# iGEM_2026_koamaba_fes

A Scratch-like game focusing on genome editing.

塩基配列ブロックをドラッグ&ドロップでつなげて遺伝子回路を組み、転写・翻訳のシミュレーション(常微分方程式によるモデルと、分子1個ずつのブラウン動力学モデルの両方)で結果を確認できるWebアプリです。さらに、遺伝子産物を粗視化(コース・グレイン)モデルとして3D分子動力学(Go模型・ランジュバン動力学)で可視化する機能も備えています。

- `index.html` / `style.css` / `app.js` / `mollook.js` / `transcription.js` / `enzyme.js` / `crowding.js` — アプリ本体(外部サーバー不要)
- ブラウザで `index.html` を直接開くか、GitHub Pagesを有効化すればWeb上でも公開できます

## Webでプレイする

**▶ https://yonage.github.io/iGEM_2026_koamaba_fes/**

`main` ブランチに push すると、GitHub Actions(`.github/workflows/pages.yml`)が自動で GitHub Pages にデプロイします。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に設定してください。

## コンセプトの由来

本プロジェクトは [iGEM UTokyo 2022「Genochemy」](https://2022.igem.wiki/utokyo/genochemy/)([実装](https://github.com/iGEM-UTokyo/genochemy))のコンセプトを参考に、UI/操作系を独自に再構成し、3D分子動力学など新しい機能を加えて開発しています。

## ステージ（ゲームモード）

「ステージ」タブに、海の重油汚染を細菌で分解するストーリー仕立ての4ステージを収録しています。
各ステージは実行結果を自動で判定し、合否と次にやることを表示します。

1. **大腸菌に重油分解酵素を作らせよう** — プロモーター→分解酵素遺伝子→ターミネーターの基本形を組み、重油を25%以上分解する
2. **様々な分解酵素を比べてみよう** — 「高速（速いが壊れやすい）」と「安定（遅いが壊れにくい）」を1回ずつ試し、立ち上がりと後半の伸びの違いを比べる
3. **分解酵素のいいところを組み合わせよう** — 2つの酵素遺伝子の間に「リンカー配列」を挟んで融合タンパク質を作り、重油を85%以上分解する
4. **特定のシグナル分子がないと死ぬようにしよう** — 「シグナル分子で抑制」プロモーター＋キルスイッチで封じ込め回路を作り、シグナルあり=生存／なし=死滅を両方確認する

### ガイド（各ステージのチュートリアル）

プログラム画面の左上に「🧭 ガイド」が表示され、各ステージを小さなステップに分けて1つずつ案内します。

- いま使うブロックやボタン（トレイのブロック・実行ボタン・Labなど）が光ります
- 操作するとステップごとに自動でチェックが付き、次のステップへ進みます
- 各ステップに「なぜそうするのか（💡）」の一言解説があります
- うまくいかないときは「お手本を置く」で、そのステップの回路を自動で配置できます
- クリアすると「わかったこと」のまとめと「次のステージへ」ボタンが出ます

- 次につなぐブロックを、目標の回路の図（ブロックの色と形をまねたもの）で示します
- はじめはトレイに今のステージで使うブロックだけを並べます（「すべてのブロックを表示」で全部出せます）
- 結果プレビューの細かい項目は、実行してから表示します
- ブロックの説明は、通常はやさしい文面、「Advanced」のときは学術寄りの文面になります

同じ進み具合は「ステージ」タブにも表示されます。ガイドは見出し部分をつかんでドラッグすると好きな場所へ動かせます。

重油の分解はミカエリス・メンテン式 `dO/dt = -Vmax·O/(Km+O)`（`Vmax = Σ kcat·P(t)`）で、
タンパク質量 `P(t)` は酵素ごとに異なる分解速度をもつODEから計算しています。
Labの「シグナル分子」スライダーは実際のシミュレーション入力で、動かすと自動で再実行されます。

## 転写と翻訳の3D分子アニメーション

画面上部の「🎬 分子の動きを見る」（実行後は結果プレビューのボタンからも）で開くポップアップの「🎬 転写と翻訳（3D）」では、
組んだ回路をそのままDNAの二重らせんとして並べ、分子生物学の3Dアニメーション
（例: [DNA Polymerase 2010](https://www.youtube.com/watch?v=sKe3UgH1AKg)）のような見た目で、遺伝子が働く流れを見せます。

1. RNAポリメラーゼがプロモーターを探して結合する（結合できる確率は回路の転写速度 k_tx から計算。リプレッサーで抑制されたプロモーターでは、リプレッサーがふさいでいて結合できない様子が見えます）
2. σ因子の助けで二重らせんがほどけ、転写バブルができる
3. 飛び回るヌクレオチド(NTP)のうち、鋳型DNAと対になるものが1つずつ取り込まれ、mRNAが伸びる（ピロリン酸が外れて飛んでいく）
4. ターミネーターでRNAがヘアピンを作り、ポリメラーゼが外れる（ターミネーターがないとDNAの端まで読み過ごす）
5. リボソームがmRNAに結合し、tRNAが運んでくるアミノ酸をつないでタンパク質を作る
6. タンパク質の鎖が折りたたまれて放出される（融合タンパク質は2つのドメインに、GFPは光る）

NTP・遊離したRNA鎖・タンパク質鎖は、ビーズとばねの高分子モデルを過減衰ランジュバン方程式で動かしています。
ヘアピンや球状の折りたたみは、相補塩基どうし・ドメイン内の引力から自然に生じます。
ポリメラーゼやリボソームの移動など、反応の進み方は演出として決めています。
画面上部のミニマップで、いまDNAのどこを読んでいるかが分かります。速さの変更・一時停止・全画面表示もできます。

## 酵素の可動部分と触媒サイクル

同じポップアップの「🧬 酵素の動き（3D）」で、回路で発現させた
酵素の**動く仕組み**を粗視化MDで見られます。

- **ヒンジ運動** — 融合酵素は「触媒ドメイン＋リンカー＋安定化ドメイン」の2ドメイン構成に
  なります。リンカー部には角度拘束も天然コンタクトも入れていないため、2つのドメインが
  自由に振れます(ドメイン間角度 約110〜145°)
- **活性部位の開閉** — 触媒ドメインは2ローブ構成で、裂け目の「底」だけを天然コンタクトで
  留めています。上部は開放されているため、熱ゆらぎで開閉します
- **触媒サイクル** — 基質(アルカン鎖)が拡散 → 活性部位に捕捉 → 保持 → 切断 →
  生成物が離脱。回転数と回転速度を計測します
- **温度による失活** — 天然コンタクトの強さを酵素の安定性パラメータに連動させています。
  同じ構造・同じ温度でも、壊れやすい酵素が先に構造を失います

| kT | 高速(安定性0.88) | 標準(1.3) | 安定(2.0) |
|---|---|---|---|
| 0.3〜2.5 | Q≈100% | Q≈100% | Q≈100% |
| 4 | **Q=55%** | Q=89% | Q=91% |
| 6 | **Q=36%** | Q=38% | **Q=77%** |

(Q = 天然コンタクト形成率。ステージ2の「壊れやすさ」が構造レベルで現れます)

## 細胞内分子夾雑シミュレーション(全画面)

上部の「🔬 細胞内を見る」から、大腸菌の細胞質を**実際の細胞内濃度のまま**再現した
3Dブラウン動力学シミュレーションを全画面で開けます。

細胞1個には約300万個のタンパク質があり全部は描けないため、細胞質から一辺
80〜260 nm の立方体を切り出して計算します。この範囲なら実濃度のまま扱えるので、
体積占有率は実際の細胞質と同じ **約26%** になります(分子数 2,400〜43,000個)。

- 過減衰ランジュバン方程式 `dx = (D·F/kT)·dt + sqrt(2D·dt)·ξ` による拡散
- 排除体積はソフトコア斥力、境界は周期境界条件
- 近接探索はセルリスト法 + Verletスキン(大きい粒子側がペアを登録する方式)
- 拡散係数はストークス・アインシュタインの関係 `D ∝ 1/r` から算出
- 平均二乗変位 `MSD = 6Dt` から**見かけの拡散係数**を実測し、自由拡散と比較できます
- 回路で発現させたタンパク質が、発現量に応じた分子数で実際に配置されます

排除体積だけでも拡散は約3割遅くなります(分子夾雑効果)。実際の細胞ではさらに
非特異的結合などが加わるため、より大きな減速が観測されることが知られています。

## 主な機能

- ドラッグ&ドロップでのブロックプログラミング(プロモーター・RBS相当・遺伝子・ターミネーターなど)
- 常微分方程式(ODE)によるmRNA/タンパク質発現シミュレーション
- 細胞内分子(RNAポリメラーゼ・リボソーム・mRNA・タンパク質)のブラウン動力学(2Dシミュレーション)
- 酵素のドメイン運動・活性部位の開閉・触媒サイクルの粗視化3D分子動力学(Go模型+ランジュバン熱浴)
- Genomy(仮想微生物)の蛍光発現・キルスイッチなどの可視化
- 重油分解シミュレーション(ミカエリス・メンテン式)と、自動判定つきの4ステージ
- 細胞内分子夾雑の大規模3Dシミュレーション(最大約43,000分子、全画面表示)
